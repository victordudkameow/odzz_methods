## 📌 О проекте

Репозиторий содержит **комплексную методику и программную реализацию** мониторинга экологических последствий гидротехнических объектов Туркменистана на основе данных дистанционного зондирования Земли (ДЗЗ) и реанализа ERA5.

### 🎯 Цель
Оценить последствия реализации гидротехнических объектов с 2000-х годов: выявить, картографировать и интерпретировать изменения земного покрова на территориях реализации проектов.

### 🗺️ Объекты исследования
| № | Объект | Тип |
|---|--------|-----|
| 1 | Зеидское водохранилище | Экосистемный объект |
| 2 | Хауз-Ханское водохранилище | Хозяйственное |
| 3 | Копетдагское водохранилище | Хозяйственное |
| 4 | Озеро «Алтын Асыр» (Каракум) | Северо-Туркменский коллектор |
| 5 | Коллектор Северного Туркменистана | Мелиоративный |
| 6 | Достлукское водохранилище | Трансграничное (Иран–Туркменистан) |

## 🔬 Методология

Методика состоит из **трёх последовательных этапов**, реализованных в связке `Google Earth Engine → ArcGIS → Python`.

### Этап 1. Предобработка в Google Earth Engine (JavaScript)
- Формирование **безоблачных годовых композитов** (март–август) по медианной фильтрации для Landsat 7/8.
- Расчёт спектральных индексов:
  - **MNDWI** — выделение водных поверхностей;
  - **NDTI** — детектирование мутных участков и прибрежных зон;
  - **SI-9** `(NIR × R) / G` — индекс засоления почв;
  - **NDVI** — оценка растительного покрова.
- **Непараметрическая кластеризация K-Means** (обучение на репрезентативном году, например 2007) с применением ко всем годам периода — это обеспечивает **согласованность классов во времени**.
- Кодирование истории каждого пикселя в виде **N-значного кода траектории** (например, 15-значного для 2000–2014), где каждая цифра — класс в конкретном году.
- Экспорт результатов в SHP / CSV / GeoTIFF.

### Этап 2. Пространственный анализ в ArcGIS
- Расчёт геометрии полигонов (площадь в м²).
- Визуальная верификация классов по диаграммам спектральных значений.
- Экспорт атрибутивной таблицы в CSV.

### Этап 3. Статистический анализ в Python
- Нормализация и очистка кодов траекторий.
- Извлечение классов по годам.
- Расчёт статистики: площадь, количество пикселей, процентное распределение.
- Построение **матриц переходов** между классами (абсолютные значения и %).
- Анализ «судьбы классов» — куда перешли пиксели исходного класса за период.
- Визуализация: stacked bar charts, линейные тренды, heatmaps.

## 🚀 Использование

### 1. Запуск скриптов в Google Earth Engine

#### 📊 Скрипт 1: ERA5 — климатический анализ
Откройте [Code Editor](https://code.earthengine.google.com/) и вставьте код из `gee_scripts/era5_monthly_temperature.js`.

**Что делает:**
- Загружает коллекцию `ECMWF/ERA5/MONTHLY`.
- Рассчитывает среднюю температуру воздуха (`mean_2m_air_temperature`) по каждому месяцу за 2000–2020 гг.
- Выводит 12 слоёв на карту с палитрой от белого до тёмно-синего (диапазон 270–300 K).

**Что даёт:** возможность выявить наиболее влажные/засушливые периоды для выбора репрезентативных дат космоснимков.

#### 🛰️ Скрипт 2: Кластеризация и коды траекторий
⚠️ **Перед запуском** создайте геометрию региона исследования и назовите её `rgn`.

**Что делает:**
1. Создаёт 15 годовых композитов (2000–2014) для веснно-летнего сезона.
2. Добавляет индексы MNDWI, NDTI, NIR_R_G.
3. Обучает K-Means (5 кластеров) на базовом году (2007).
4. Применяет модель ко всем 15 годам.
5. Формирует 15-значный код траектории для каждого пикселя.
6. Экспортирует:
   - `Trajectory_L7_15digit_2000-2014_SHP` — векторный слой;
   - `Trajectory_L7_15digit_2000-2014_CSV` — таблица;
   - `Trajectory_L7_15digit_Raster_2000-2014` — растр GeoTIFF;
   - `Cluster_Base_L7_2007_Model` — базовая классификация.

**Что даёт:** компактное хранение полной истории изменений ландшафта в одном атрибуте — одна строка = одна траектория за 15 лет.

---

### 2. Анализ траекторий в Python

Откройте Jupyter-ноутбук `trajectory_yearly_analysis.ipynb` и запустите ячейки.

#### Интерактивный ввод параметров:
```
📂 Путь к файлу:                 data/tableofclasses.csv
📅 Начальный год:                2014
📅 Год окончания:                2025
🏷️  Количество классов:          5
   Класс 0: пустыня
   Класс 1: засоление(солончак)
   Класс 2: растительность
   Класс 3: зона засоления(галофитной растительности)
   Класс 4: вода
```

#### Автоматически выполняются:
1. Загрузка CSV и очистка кодов траекторий (обработка scientific notation, пробелов, NaN).
2. Нормализация длины траектории (обрезка с начала / дополнение нулями).
3. Извлечение классов по годам.
4. Расчёт статистики по годам (пиксели + площадь).
5. Анализ переходов между годами.
6. Анализ «судьбы классов» — куда мигрировали пиксели исходного класса.
7. Построение графиков:
   - `area_distribution_by_year.png` — stacked bar chart;
   - `yearly_area_trends.png` — линейные тренды;
   - `transition_yearly_abs_*.png` — матрицы переходов (абс.);
   - `transition_yearly_pct_*.png` — матрицы переходов (%);
   - `transition_yearly_summary.png` — сводная сетка всех переходов;
   - `dynamics_yearly_<class>.png` — динамика каждого класса.

## 📈 Что дают результаты

### Количественные показатели
- **Площадь** каждого класса по годам (в м² и %).
- **Топ-20 переходов** между классами с указанием площади.
- **Процент устойчивости** класса (сколько пикселей осталось в исходном классе).

### Качественные выводы (на примере объектов)
| Объект | Ключевые findings |
|--------|-------------------|
| **Зеидское вдхр.** | Пик увлажнения 2005 г. (+40% галофитов), тенденция к опустыниванию после 2020 г. |
| **Хауз-Ханское вдхр.** | Прямой переход «засоление → вода» в засушливые годы — ухудшение качества воды |
| **Копетдагское вдхр.** | Обмеление 2023 г. — засоленные и пустынные земли заняли ~50% площади |
| **Озеро Каракум** | Критическое засоление, вода непригодна для хоз. нужд, концентрация солей растёт |
| **Коллектор Сев. Туркменистана** | Пустыня к 2025 г. заняла 70% площади — коллектор **усугубляет** опустынивание |
| **Достлук** | Обмеление 2023 г. из-за засухи и трансграничного водозабора |

### Декодирование N-значного кода в Excel
Для ячейки `A2` с 15-значным кодом:
```excel
2000: =FLOOR(MOD(A2;10^15)/10^14;1)
2001: =FLOOR(MOD(A2;10^14)/10^13;1)
...
2014: =MOD(A2;10)
```
